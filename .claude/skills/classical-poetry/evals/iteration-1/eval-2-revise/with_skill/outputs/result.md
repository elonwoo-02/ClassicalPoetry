# 七绝《山雨》格律检查与修改建议

> 诗体：七绝 | 韵部：平水韵·十一尤 | 格式：仄起首句入韵式

## 原诗

```
山雨欲来风满楼，乌云密布压城头。
忽然一道金光闪，万物重归平静秋。
```

---

## 格律检查全流程

### 第一步：平仄逐句标注

**应合格式（七绝仄起首句入韵）**：

| 句序 | 标准格式 |
|------|----------|
| 句1 | 仄仄平平仄仄平 |
| 句2 | 平平仄仄仄平平 |
| 句3 | 平平仄仄平平仄 |
| 句4 | 仄仄平平仄仄平 |

**逐句标注**：

| 句 | 诗句 | 实际平仄 | 应合格式 | 合律 |
|----|------|----------|----------|------|
| 1 | 山雨欲来风满楼 | ○●○ ○●○ | 仄仄平平仄仄平 | 基本合律* |
| 2 | 乌云密布压城头 | ○○● ●●○ | 平平仄仄仄平平 | ✓ |
| 3 | 忽然一道金光闪 | ●○● ●○● | 平平仄仄平平仄 | 出律 |
| 4 | 万物重归平静秋 | ●●○ ○●○ | 仄仄平平仄仄平 | 出律 |

**入声字标注**：
- 欲：古入声字（屋韵），仄声
- 密：古入声字（质韵），仄声
- 压：古入声字（压韵），仄声
- 忽：古入声字（月韵），仄声
- 一：古入声字（质韵），仄声
- 物：古入声字（物韵），仄声

**说明**：
- 句1：七言第一字可平可仄，"山"用平声无妨（一三五不论）。第三字"欲"为仄声，格律应平；但第五字"风"为平声，恰好构成**孤平拗救**（第三字拗仄，第五字救平），故句1合律。
- 句3：第一字"忽"为仄声（入声），应平，但七言第一字可不论。**第三字"一"为仄声（入声），应平**，此处出律。且"一"在第三位，无法用第五字救（第五字"金"为平声，但"平平仄仄平平仄"格式中第三字拗、第五字用平并不构成标准救法）。
- 句4：第一字"万"为仄声，应平，可不论。**第三字"重"为平声，应仄**，此处出律。第五字"平"为平声，应仄，可不论但存在问题。

### 第四步：对仗检查（绝句不强制要求对仗，但可分析）

本诗为七绝，对仗不强制。但句1与句2之间可视为宽对：
- 句1"山雨欲来"（主谓结构）vs 句2"乌云密布"（主谓结构）→ 结构相对
- 句1"风满楼" vs 句2"压城头" → 结构不完全对仗

句3与句4之间无对仗。

**建议**：绝句不要求对仗，无需修改。

| **孤平** | 山(○)雨(●)欲(●)来(○)风(○)满(●)楼(○) → 除韵脚外有山、来、风三平声，**无孤平** ✓ | 无孤平 ✓ | 句3为仄脚句，不涉及孤平问题 ✓ | 万(●)物(●)重(○)归(○)平(○)静(●)秋(○) → 除韵脚外有重、归、平三平声，**无孤平** ✓ |

| **三仄尾** | 句末"风满楼"为○●○ ✓ | 句末"压城头"为●○○ ✓ | 句末"金光闪"为○○● ✓ | 句末"平静秋"为●○○ ✓ |

**病格结论**：无严重病格 ✓

### 第六步：拗救说明

句1：第三字"欲"（仄）拗，第五字"风"（平）救 → 本句自救（孤平拗救）✓

句3：第三字"一"（仄）应平，但此处格式为"平平仄仄平平仄"，第三字拗后标准救法是让对句（句4）第三字用平声相救。但句4第三字"重"为平声，原本格式"仄仄平平仄仄平"中第三字即为平，因此对句并未形成有意识的相救。**建议修改句3第三字。**

句4：第三字"重"（平）应仄，第五字"平"（平）应仄。此处两句均存在问题，需调整。

## 章法分析

### 起承转合

| 环节 | 对应诗句 | 分析 |
|------|---------|------|
| **起** | 山雨欲来风满楼 | 以"山雨欲来风满楼"起笔，化用许浑名句，营造暴雨将至的紧张氛围。明起，直接入题。 |
| **承** | 乌云密布压城头 | 承接上句，进一步渲染乌云压城的压抑感。"压"字有力，增强画面张力。 |
| **转** | 忽然一道金光闪 | 从压抑转向爆发——闪电划破天际。转折有力，节奏变化好。 |
| **合** | 万物重归平静秋 | 雨后的宁静，收束全诗。但"平静秋"略显平淡，且"秋"字点明季节，与前文景物缺少呼应。 |

### 意象分析

- 山雨、乌云、金光（闪电）→ 暴雨将至 → 爆发 → 宁静，画面递进合理
- 前两句写压抑，第三句转折，第四句收束，章法结构完整

### 问题诊断

1. **格律问题**：
   - 句3第三字"一"（入声仄）应平，出律
   - 句4第三字"重"（平）应仄，出律

2. **炼字问题**：
   - "万物重归平静秋"："重归"与"平静"搭配略显生硬。"平静秋"作为收束，意象偏弱，与前两句的磅礴气势形成落差过大
   - "忽然一道金光闪"：较为现代口语化，古诗中"忽"单用即可，"一道金光"略显直白
   - "乌云密布压城头"："压城头"有气势，但"城头"略显泛泛

3. **意境问题**：
   - 前两句重墨渲染山雨欲来之势，后两句收束过快，从"金光闪"到"平静秋"之间缺少过渡
   - 第四句"秋"字出现在最后，前面没有任何秋景铺垫，略感突兀

## 修改稿

### 修改稿一（最小改动，仅调整平仄）

```
山雨欲来风满楼，乌云密布压城头。
俄然一道金光闪，万物重归静好秋。
```

**修改说明**：
| 原字 | 改字 | 位置 | 理由 |
|------|------|------|------|
| 忽(仄) | 俄(平) | 句3第一字 | "忽"为入声仄，第一字虽可不论，但"俄"字更雅，且为平声，更合律 |
| 一(仄) | — | 句3第三字 | 此处第三字应平，"一"为入声仄声，出律。但"一"字在"一道"中难以替换（"一闪"可接受），若保留"一"则需解释为出律 |
| 平(平) | 好(仄) | 句4第五字 | "平"在第五位应仄，改为"好"，"静好秋"意境更佳 |

### 修改稿二（全面调整）

```
山雨欲来风满楼，乌云压阵暗城头。
长空裂破金蛇走，万籁倏归一色秋。
```

**修改说明**：

| 原句 | 改句 | 修改理由 |
|------|------|---------|
| 乌云密布压城头 | 乌云压阵暗城头 | 删"密布"二字，改为"压阵"更精炼；"压城头"变"暗城头"，"暗"字为仄声，与第二字"云"(平)构成意对，且"暗"字渲染阴沉氛围，为后文闪电蓄势 |
| 忽然一道金光闪 | 长空裂破金蛇走 | "长空裂破"四字全仄（仄平仄仄），但这是有意为之的拗句，模拟闪电撕裂长空的震撼效果；"金蛇走"比喻闪电如金蛇游走，比"金光闪"更生动形象 |
| 万物重归平静秋 | 万籁倏归一色秋 | "万籁"比"万物"更贴切（声音层面的寂静）；"倏归"（忽然回归）与"金蛇走"的动感呼应；"一色秋"化用"秋水共长天一色"，展现雨后天地澄明、万物一色的秋意 |

**修改稿二格律自审**：

| 句 | 诗句 | 平仄 | 合律 |
|----|------|------|------|
| 1 | 山雨欲来风满楼 | ○●○ ○●○ | ✓（孤平拗救） |
| 2 | 乌云压阵暗城头 | ○○● ●●○ | ✓ |
| 3 | 长空裂破金蛇走 | ○○● ●○● | 出律（第三字"裂"入声仄，应平；第五字"金"平，可救） |
| 4 | 万籁倏归一色秋 | ●●○ ○●○ | ✓（"倏"入声仄，"一"入声仄，"归"平，此处"一三五不论"） |

句3说明：此句有意用拗格，以声音上的"裂破"感配合内容。第三字"裂"虽为仄声，但全句气势雄浑，可视为意胜于律的特殊处理。若严格守律，可改为"长空忽裂金蛇走"（○○●●○○●），但"忽裂"不如"裂破"有力，此处保留"裂破"。
