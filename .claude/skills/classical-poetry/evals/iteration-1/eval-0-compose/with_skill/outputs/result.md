# 七绝·秋日登高远眺

> 诗体：七绝 | 韵部：平水韵十一尤 | 格式：仄起入韵式

## 原诗
```
独上秋山万仞头，
霜林尽染暮云收。
长空万里天如洗，
极目苍茫意未休。
```

## 创作说明
秋日独登高山，万仞之巅放眼远眺，霜林暮云尽收眼底，长空万里如洗，苍茫天地间豁然开朗，表达登高望远后心旷神怡、意气未尽的超然心境。

## 章法分析
- **起**：以"独上秋山万仞头"开篇，直入主题，明起手法。"独"字点明独自一人，"万仞头"极言山高，为远眺铺垫。
- **承**："霜林尽染暮云收"承接登山所见，霜林（秋色）、暮云（天象）一近一远，一实一虚，勾勒出秋日黄昏的苍茫画面。
- **转**："长空万里天如洗"陡然转折，由近景转向远景，由地面转向天空。"天如洗"三字将视野推向极致，心境随之豁然开朗，是全诗关键转折。
- **合**："极目苍茫意未休"收束全诗，极目远眺苍茫天地，登高之兴未尽，意蕴悠长，言有尽而意无穷。

## 炼字说明
| 位置 | 字 | 用意 |

| 首句二字 | 独上 | "独"字点明孤身一人登山，更显超然洒脱；"上"字动词，有向上攀登的动感 |
| 首句四字 | 万仞 | 夸张手法，极写山势之高，为远眺铺垫高度 |
| 次句首字 | 霜 | "霜"字点明秋令，白描中见秋意 |
| 三句首字 | 长 | "长空"二字，一"长"字拓宽空间感，天地苍穹尽收眼底 |
| 三句末字 | 洗 | "天如洗"的"洗"字是诗眼，以水洗喻天，赋予天空澄澈透明的质感，通感手法，使抽象的天色具象化 |
| 末句三字 | 苍茫 | 叠韵连绵词，既是景（苍茫天地），又是情（苍茫之感），情景交融 |
| 末句末字 | 休 | "意未休"以否定收束，言有尽而意无穷，登高之兴永不消散 |
