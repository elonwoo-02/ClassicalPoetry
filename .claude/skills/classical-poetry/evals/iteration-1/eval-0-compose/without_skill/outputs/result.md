# 秋日独自登山远眺

## 七绝

**《秋日登高》**

独上秋山望眼开，<br>
千峰如画入襟怀。<br>
浮云过眼皆成幻，<br>
万里长风送雁来。

---

## 格律检查

### 押韵（平水韵）

| 韵脚 | 字 | 所属韵部 |
|------|----|---------|
| 第1句末 | **开** | 十灰（平声） |
| 第2句末 | **怀** | 十灰（平声） |
| 第4句末 | **来** | 十灰（平声） |

- 押韵方式：**首句入韵**，一、二、四句押韵，韵脚为"开、怀、来"，同属 **平水韵·十灰**。

### 平仄格式（仄起首句入韵式）

| 句式 | 平仄 | 说明 |

| 万里长风送雁来 | **仄仄平平仄仄平** | 对句相粘，合律 ✓ |

- 起式：**仄起平收**（首句第二字"上"为仄声，末字"开"为平声）
- 全诗无人声字混入问题，平仄基本合规。
- 第三句与第二句失粘，属折腰体（唐代诗人常用变格），不影响格律认定。

### 对仗

- 七绝不对仗作硬性要求。
- 颔联（第三、四句）可看作宽对，意脉贯通，虚实相生。

## 简要赏析

1. **起句**"独上秋山望眼开"：破题——"独"字点明独自登山，"望眼开"写登高后视野豁然开朗，心境为之舒展。
2. **承句**"千峰如画入襟怀"：远眺所见，群峰如画卷般展开，一个"入"字将客观景物与主观胸怀融为一体，体现豁达。
3. **转句**"浮云过眼皆成幻"：由景入理，以浮云之变喻世事无常，以"皆成幻"表超然物外之态，为全诗意境的升华。
4. **合句**"万里长风送雁来"：以景收束，"长风"与"万里"呼应前文的"千峰"，"雁来"既点秋令，又寄寓归思与高远之志，言尽而意无穷。

全诗借秋日登高之景，抒发不为浮云所蔽、心随长风万里的豁达胸怀，契合"登高望远之豁达心境"之旨。
