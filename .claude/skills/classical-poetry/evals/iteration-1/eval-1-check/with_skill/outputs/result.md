# 格律检查分析报告

> 诗体：七言绝句（集句诗）| 韵部：平水韵 上平十五删 | 格式：平起不入韵式

## 原诗

```
春风又绿江南岸，明月何时照我还。
桃花流水窅然去，别有天地非人间。
```

> **说明**：此诗为集句诗（Cento），前两句出自王安石《泊船瓜洲》，后两句出自李白《山中问答》。以下按**七绝平起不入韵式**进行格律检查。

### 三平调详解

第④句"别有天地**非人间**"：
- 非(○) 人(○) 间(○) — 句末三字连续平声
- 在仄脚句（标准格式应押仄声）中出现三平调，属于**格律大忌**
- 近体诗严禁三平调，这是古体诗的特征

## 第六步：拗救说明

### 本句自救情况

| 句 | 是否存在拗救 | 说明 |
|----|-------------|------|
| ①春风又绿江南岸 | 无 | 完全合律，无需拗救 |
| ②明月何时照我还 | 无 | 完全合律，无需拗救 |
| ③桃花流水窅然去 | 无法通过拗救解决 | 第二、四、六字全部失律，非单一拗字可救 |
| ④别有天地非人间 | 无法通过拗救解决 | 三平调为绝对禁忌，无拗救方案 |

### 对句相救可能性

第③句与第④句之间：第③句平仄严重错乱，即使第④句调整也无法通过"对句相救"弥补，因为第④句本身存在三平调。

### 特定变格检查

第③句"○○○●●○●"看起来接近"仄仄平平仄平仄"（七言特定变格，即第5、6字平仄互换），但第③句标准格式为"仄仄平平平仄仄"，其变格应为"仄仄平平仄平仄"。而实际"桃花流水窅然去"的第二字"花"(○)应为仄，第四字"水"(●)应为平，均与变格不符，故不成立。

## 综合结论

### 问题汇总

| 序号 | 问题类型 | 严重程度 | 具体位置 | 说明 |
|------|----------|----------|----------|------|
| 1 | 平仄失律 | 严重 | 第③句第2字"花" | 应仄实平 |
| 2 | 平仄失律 | 严重 | 第③句第4字"水" | 应平实仄 |
| 3 | 平仄失律 | 严重 | 第③句第6字"然" | 应仄实平 |
| 4 | 失粘 | 较重 | 第②↔③句之间 | 第二字"月(●)"与"花(○)"不粘 |
| 5 | **三平调** | **致命** | 第④句末"非人间" | 句末三字连平，格律大忌 |
| 6 | 平仄失律 | 较重 | 第④句第5字"非" | 应仄实平（与三平调关联） |

### 整体评价

此诗作为集句诗，前两句（王安石《泊船瓜洲》）格律规范，完全合律。后两句（李白《山中问答》）属于古体诗风格，不符合近体诗格律要求。全诗存在 **1处致命问题（三平调）**、**4处平仄失律**、**1处失粘**，不符合七绝格律标准。

### 修改建议

#### 方案一：保留原意，调整字词入律

**修改后版本**：
```
春风又绿江南岸，明月何时照我还。
桃花逐水窅然去，别有天地在人间。
```

| 原句 | 修改 | 修改理由 |
|------|------|----------|
| 桃花流水窅然去 | 桃花**逐**水窅然去 | "流水"→"逐水"：流(○)改逐(●，入声)，使第二字花(○)虽仍不是标准仄声，但"逐"入第四字(改为仄)拉近格式。但此方案仍不够理想 |
| 别有天地非人间 | 别有天地**在**人间 | "非"(○)→"在"(●)，解决三平调问题 |

**更彻底的修改**：
```
春风又绿江南岸，明月何时照我还。
桃花流水飘然去，别有天地在人间。
```
（"窅"改为"飘"飘(○)虽不是仄声，但可调整整体节奏；"在"替换"非"解决三平调）

但这样改变了原诗的意境。

#### 方案二：承认古体诗特征，作为古绝处理

如果将此诗视为**古绝**（古体绝句，不严格要求格律），则不需要修改。古绝允许三平调、允许平仄自由。建议注明"此诗为集句古绝，非近体格律诗"。

#### 推荐方案

鉴于前两句是严谨的近体诗（王安石），后两句是李白的古体诗风格，建议：
- 如要作为**近体诗七绝**发表，请按方案一修改
- 如保留原句，请在诗题或注释中注明"古绝"或"集句"
