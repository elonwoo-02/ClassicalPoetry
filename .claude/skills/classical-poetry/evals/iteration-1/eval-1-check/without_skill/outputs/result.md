# 格律分析报告

## 待分析文本

```
春风又绿江南岸，明月何时照我还。
桃花流水窅然去，别有天地非人间。
```

---

## 一、来源考辨：此诗实为两首名作的拼接

| 行号 | 出处 | 作者 | 原诗 |
|------|------|------|------|
| 第1-2句 | 《泊船瓜洲》 | 王安石（宋） | 京口瓜洲一水间，钟山只隔数重山。**春风又绿江南岸，明月何时照我还。** |
| 第3-4句 | 《山中问答》 | 李白（唐） | 问余何意栖碧山，笑而不答心自闲。**桃花流水窅然去，别有天地非人间。** |

> **首要问题**：这四句并非同一首诗，而是将两首不同朝代、不同作者、不同格律的诗作各取两句拼合而成。这在格律分析上属于根本性错误。

## 三、拟用格律范式比对

### 3.1 判定基本格式

第1句末字"岸"为仄声，第2句末字"还"为平声，第4句末字"间"为平声，符合七言绝句**首句不入韵**（仄起不入韵式或平起不入韵式）的基本特征。

第1句平仄为"平平仄仄平平仄"，对应**平起不入韵式**：

```
（平）平（仄）仄平平仄，（仄）仄平平仄仄平。
（仄）仄（平）平平仄仄，（平）平（仄）仄仄平平。
```

### 3.2 逐句比对

| 实际 | 春(平) | 风(平) | 又(仄) | 绿(仄) | 江(平) | 南(平) | 岸(仄) |
| 判定 | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ |

**结果：完全合律。** 第1句平仄无一字出格。

#### 第2句 vs 范式第2句

| 位置 | 1 | 2 | 3 | 4 | 5 | 6 | 7 |
|:-:|:-:|:-:|:-:|:-:|:-:|:-:|:-:|

**分析：** 第1字"明"为平声，范式要求仄声。按"一三五不论"原则，第1字本可灵活，但此处存在一个隐患：

- 范式"(仄)仄平平仄仄平"中，若第1字改平，则变为"平仄仄平仄仄平"，会导致**孤平**（仅剩第4字一个平声）。
- 但本句实际为"平仄**平**平仄仄平"，第3字"何"为平声，因此并未形成孤平。
- **结论：有瑕疵但在允许范围内，不算严重出律。**

## 四、专项问题分析

### 4.1 押韵分析

| 句序 | 末字 | 韵部（平水韵） | 平仄 |
|:----:|:----:|:--------------:|:----:|
| 第1句 | 岸 | 去声十五翰 | 仄声 |
| 第2句 | 还 | 上平十五删 | 平声 |
| 第3句 | 去 | 去声六御 | 仄声 |
| 第4句 | 间 | 上平十五删 | 平声 |

**分析：**
- 七言绝句的押韵规则：平声韵（首句仄收可不入韵），第2句和第4句必须押韵，且押平声韵。
- 第2句"还"和第4句"间"均为上平十五删韵，**韵部一致，押韵成立**。✅
- 第1句"岸"为仄声，属首句不入韵，符合规则。✅
- 第3句"去"不要求押韵，符合规则。✅

**押韵方面没有问题。**

### 4.2 尾三平问题（三平调）

第4句末三字为"非人间" = 平平平，形成**尾三平（三平调）**。

> 尾三平是格律诗的大忌（尤其近体诗），被认为是最严重的出律形式之一。古体诗中可接受，但近体诗（绝句、律诗）中严格禁止。

**结论：第4句尾三平，严重出律。**

### 4.3 粘对分析

| 位置 | 第1句第2字 | 第2句第2字 | 第3句第2字 | 第4句第2字 |
|:----:|:----------:|:----------:|:----------:|:----------:|
| 实际 | 风(平) | 月(仄) | 花(平) | 有(仄) |

**粘（第2句第2字与第3句第2字）：** 月(仄) vs 花(平) —— 应"粘"（同声调），实际"对"（相反），**失粘** ❌

**对（第1句第2字与第2句第2字）：** 风(平) vs 月(仄) —— 应"对"（相反），实际相反，**合对** ✅

## 六、修改建议

### 方案一：保留王安石《泊船瓜洲》原诗（完整七绝）

```
京口瓜洲一水间，钟山只隔数重山。
春风又绿江南岸，明月何时照我还。
```

**格律范式：仄起平收式（首句入韵）**
```
(仄)仄平平仄仄平，(平)平(仄)仄仄平平。
(平)平(仄)仄平平仄，(仄)仄平平仄仄平。
```

此诗完全合律，无需修改。

### 方案二：保留李白《山中问答》原诗（完整七绝）

```
问余何意栖碧山，笑而不答心自闲。
桃花流水窅然去，别有天地非人间。
```

**说明：** 李白此诗实际是**古体绝句（古绝）**，而非格律严谨的近体绝句。古体诗不严格要求平仄粘对，但仍有入韵要求。此诗首句入韵（山、闲、间，上平十五删韵），押韵完全正确。

### 方案三：若仍要保留现有四句并整改为格律诗

若试图将这两组句子拼合为一首**平起不入韵式**七言绝句，可做如下修改：

```
（原句）春风又绿江南岸，明月何时照我还。
（修改）桃花逐水悠然去，此处风光非世间。
```

| 句 | 修改说明 |
|:--|:---------|
| 第3句 | "桃花流水窅然去" → "桃花逐水悠然去"（平平仄仄平平仄），合平起不入韵式第3句范式 |
| 第4句 | "别有天地非人间" → "此处风光非世间"（仄仄平平仄仄平），纠正尾三平，且"间"保留原韵部 |

## 七、最终结论

| 项目 | 结论 |
|:----|:-----|
| 来源完整性 | ❌ 四句分属两首不同诗作，不是一首完整的诗 |
| 押韵 | ✅ 第2句"还"与第4句"间"同属上平十五删韵，押韵正确 |
| 第1句平仄 | ✅ 完全合律 |
| 第2句平仄 | ⚠ 第1字"明"平声有孤平隐患，但第3字"何"为平声，未构成孤平 |
| 第3句平仄 | ❌ 多处出律（第2、4、6位均不合范式） |
| 第4句平仄 | ❌ 第2位出律 + 尾三平（"非人间"为三平调，近体诗大忌） |
| 粘对 | ⚠ 第2-3句失粘 |

**总体评价：** 这四句从文学意境上看，前后贯通、浑然天成，是千古传诵的佳句。但从近体诗格律角度严格审视，存在严重的格律问题，根源在于它们本不属于同一首诗。建议根据上述方案选择使用原诗，或按照格律规则进行修改。
