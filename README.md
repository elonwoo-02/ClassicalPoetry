# ClassicalPoetryR

格律诗写作个人知识管理系统 —— 以杨祥雨《格律诗写作自学教程》为核心教材，
围绕"格律诗写作能力成熟度模型"构建的七领域知识体系。

---

## 系统总览

### 知识成熟度树

```
                格律诗写作
                    │
 ┌──────────────────┼──────────────────┐
 │                  │                  │
格律基础           写作能力            诗人修养
能不能写           写什么             为什么写
 │                 │                  │
平仄              意境                 阅读
押韵              立意                 体验
对仗              情景交融              审美
```

### 知识成熟度路径

1. **格律基础** — 掌握平仄、押韵、对仗等"能不能写"的基础
2. **写作能力** — 培养意境、立意、情景交融等"写什么"的能力
3. **章法结构** — 学习起承转合等"怎么组织"的结构方法
4. **表达技巧** — 应用描写、抒情、用典等"如何写得好"的技巧
5. **创新方法** — 实践独具只眼等"如何避免重复"的创新手法
6. **诗人修养** — 培养人生体验、审美等"为什么写"的底蕴
7. **句法系统** — 精通省略、倒装等"如何炼语言"的句法

### 训练方法

1. 先解析名篇（`名篇解析/`），理解格律与章法
2. 逐项专项训练（平仄 → 押韵 → 对仗 → 炼字）
3. 仿写经典（`仿写训练/`）
4. 自由创作实验（`创作实验/`）
5. 成熟作品移入 `04_Creations/`

### 使用规范

- 每首诗使用 `Templates/诗作模板.md` 记录
- 修改时在新文件中记录，并链接到原稿
- 完成格律检查后再移入对应诗体目录
- 成熟作品定期汇编进 `诗集/`

### 创作流程

1. 在 `00_Inbox/` 或 `03_Workbench/` 中起稿
2. 用 `Templates/格律检查模板.md` 检查格律
3. 移入对应诗体目录，使用诗作模板
4. 修改稿存于 `修改稿/`

## Claude Skills — AI 辅助工具

基于本知识库的格律诗写作体系，已构建两个 Claude Skill（位于 `.claude/skills/` 目录），可与知识体系配合使用：

### classical-poetry — 格律诗创作助手

按格律规则创作格律诗，并做格律检查与修改。

| 场景 | 功能 |
|------|------|
| 写诗 | 按平水韵+古入声字规则创作五绝/七绝/五律/七律，附完整格律自审 |
| 格律检查 | 六步系统检查：平仄逐句标注 → 粘对 → 押韵 → 对仗 → 病格 → 拗救 |
| 修改诗作 | 诊断格律+章法问题，给修改稿和修改理由 |

**核心定位**：格律技术（能不能写对）

### poem-analyzer — 名篇赏析助手

从六维框架深度拆解一首诗，揭示其为何成为佳作，并提炼可学习方法。

| 场景 | 功能 |
|------|------|
| 深度赏析 | 意境、炼字、章法、表达、匠心、文化底蕴六维全面拆解 |
| 对比分析 | 并置比较不同诗作，揭示风格差异 |
| 教学提炼 | 从赏析中提炼可操作的写作方法 |

**核心定位**：文学赏析（为什么好、好在哪里、怎么学）

### 与知识体系的配合

```
02_Knowledge（知识体系）
      ↓ 提供理论支撑
classical-poetry  →  03_Workbench（创作训练）→  04_Creations（作品）
poem-analyzer     →  03_Workbench/名篇解析
```

两个 Skill 的知识来源即本仓库的七领域知识体系。随着知识节点不断完善，Skill 的赏析与创作质量也会同步提升。
