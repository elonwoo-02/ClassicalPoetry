# 04_Creations — 创作库

按照诗体管理原创作品。

---

## 目录结构

```
04_Creations/
├── 五绝/           五言绝句作品
├── 七绝/           七言绝句作品
├── 五律/           五言律诗作品
├── 七律/           七言律诗作品
├── 排律/           排律/长律作品
├── 诗集/           定期汇编的诗集
└── 修改稿/         作品的修改记录
```

## 使用规范

1. 每首诗使用 `Templates/诗作模板.md` 记录。
2. 修改时在新文件中记录，并链接到原稿。
3. 完成格律检查后再移入对应诗体目录。
4. 成熟作品定期汇编进 `诗集/`。

## 创作流程

```
00_Inbox/或03_Workbench/中起稿
    ↓
用Templates/格律检查模板.md检查格律
    ↓
移入对应诗体目录，使用诗作模板
    ↓
修改稿存于 修改稿/
```
