# 七律格律

> 来源：杨祥雨《格律诗写作自学教程》第一编 第一章 第9讲
> 所属领域：格律基础

---

## 一、学习目标

认识七言律诗的平仄格律。

## 二、学习重点

1. 七律八句四韵或五韵，押平声韵，一韵到底。
2. 七律四种平仄格式。

## 三、学习方法

精读与识记结合，掌握格式的推导方法。

## 四、核心要点

七律专就格式而言，不过是七绝的重叠。四种格式如下：

**格式一：第一句仄起入韵**
```
仄仄平平仄仄平，平平仄仄仄平平。
平平仄仄平平仄，仄仄平平仄仄平。
仄仄平平平仄仄，平平仄仄仄平平。
平平仄仄平平仄，仄仄平平仄仄平。
```

**格式二：第一句平起入韵**
```
平平仄仄仄平平，仄仄平平仄仄平。
仄仄平平平仄仄，平平仄仄仄平平。
平平仄仄平平仄，仄仄平平仄仄平。
仄仄平平平仄仄，平平仄仄仄平平。
```

**格式三：第一句平起不入韵**
```
平平仄仄平平仄，仄zz平平仄仄平。
仄仄平平平仄仄，平平仄仄仄平平。
平平仄仄平平仄，仄仄平平仄仄平。
仄仄平平平仄仄，平平仄仄仄平平。
```

**格式四：第一句仄起不入韵**
```
仄仄平平平仄仄，平平仄仄仄平平。
平平仄仄平平仄，仄仄平平仄仄平。
仄仄平平平仄仄，平平仄仄仄平平。
平平仄仄平平仄，仄仄平平仄仄平。
```

## 五、导学诗例

```
锦瑟
李商隐

锦瑟无端五十弦，一弦一柱思华年。
庄生晓梦迷蝴蝶，望帝春心托杜鹃。
沧海月明珠有泪，蓝田日暖玉生烟。
此情可待成追忆，只是当时已惘然。
```

**成功底蕴揭示**：格式一（仄起入韵）。颔联、颈联对仗极其工整（"庄生晓梦"对"望帝春心"，"沧海月明"对"蓝田日暖"），一韵到底。
