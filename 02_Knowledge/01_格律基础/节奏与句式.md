# 节奏与句式

> 来源：杨祥雨《格律诗写作自学教程》第一编 第三章 第14讲
> 所属领域：格律基础

---

## 一、学习目标

理解格律诗写作的节奏形式。

## 二、学习重点

诗句节奏规律——五言三节奏、七言四节奏，以及节奏的特殊情况。

## 三、学习方法

比较学习。

## 四、核心要点

### 1. 格律诗节奏与语句结构的关系

格律诗的节奏形式，不仅要注意"音长"原则，还要注意"语义"原则。把节奏问题同语句结构放在一起来讲，让人朗诵时朗朗上口，同时不破坏词语结构，合于现代语言实际。

### 2. 一般节奏

格律诗句节奏，以每两个音节（两个字）为一个节奏单位，五言和七言最后一个字单独成为一个节奏单位。

**五字句**：
```
仄仄——平平——仄
平平——仄仄——平
平平——平仄——仄
仄仄——仄平——平
```

**七字句**：
```
平平——仄仄——平平——仄
仄仄——平平——仄zz——平
仄仄——平平——平仄——仄
平平——仄仄——仄平——平
```

从这个角度，"一三五不论，二四六分明"基本正确——第一、三、五字不在节奏点上，可不论；第二、四、六字在节奏点上，需分明。

**意义单位与声律单位常一致**：如"白日/依山/尽，黄河/入海/流"、"晴川/历历/汉阳/树，芳草/萋萋/鹦鹉/洲"。

### 3. 节奏的另一种情况（三字尾整体）

五言、七言的三字尾，三个音节结合比较密切，节奏点也可移动：

**五字句**：
```
仄仄——平——平仄
平平——仄——仄平
平平——平——仄仄
仄zz——仄——平平
```

如李商隐《登乐游原》"向晚——意——不适，驱车——登——古原"。

### 4. 更大的节奏单位（二三/四三）

五字句分为二三，七字句分为四三。这样分析更合于语言实际，也更富于概括性。

**例**：
- 向晚——意不适，驱车——登古原。
- 乱花渐欲——迷人眼，浅草才能——没马蹄。

### 5. 节奏的特殊情况

如李白《渡荆门送别》"山——随平野——尽，江——入大荒——流"。"随平野""入大荒"都是动宾结构作状语，按二三分开不合语法结构。

**节奏单位和语法结构的一致是常例，不一致是变例。**

### 6. 与现代民歌节奏比较

现代民歌每句大致三个节奏（也有四个），一个节奏里往往是一个词组。格律诗五言每句三个节奏，七言每句四个节奏，每句平仄相重相间。
