# 押韵

> 来源：杨祥雨《格律诗写作自学教程》第一编 第二章 第3讲、第4讲
> 所属领域：格律基础

---

## 一、学习目标

学习用韵规则，掌握《诗歌常用十三辙同韵字表》的使用方法。

## 二、学习重点

1. 用平声韵为正例，一韵到底。
2. 十三辙同韵字表的使用。

## 三、学习方法

查韵书、查字典，阅读积累。

## 四、核心要点

### 1. 韵的概念

- 韵，大致等于汉语拼音中所谓韵母（如"公"gōng中，ong是韵母）。
- **押韵**：把两个以上韵母相同或相近的字放在诗句的同一位置上（句尾），使声音和谐悦耳，又叫"韵脚"。

### 2. 格律诗押韵规则（六条）

1. **偶数句押韵**：律诗二四六八句押韵，绝句二四句押韵。首句可押可不押（五言首句不入韵为常见，七言首句入韵为常见）。
2. **只押平声韵**：格律诗正例是押平声韵，这几乎是一条雷打不变的规矩。
3. **一韵到底，中间不能换韵**（古诗允许中途换韵，格律诗不允许）。
4. **首句入韵的诗，首句韵脚可用邻韵**（称"孤燕入群"）。若不押韵，首句限用仄声字。
5. **不允许一个字重韵**。
6. **脚分明**：韵脚一定是平声，白脚一定是仄声。

### 3. 借用邻韵（孤燕入群）

首句借用邻韵必须是在诗韵里排列相近而音又相似的韵。王力分为八类：
1. 东、冬；2. 支、微、齐；3. 鱼、虞；4. 佳、灰；5. 真、文、元、寒、删、先；6. 萧、肴、豪；7. 庚、青、蒸；8. 覃、盐、咸。

### 4. 《十三辙同韵字表》使用

- **阅览诗词查韵脚**：同韵音节不要求韵母完全相同，只要韵腹（主要元音）相同即可（如麻má、家jiā、瓜guā，韵腹都是ɑ）。
- **自己写诗找韵脚**：先定声调选韵脚字音 → 识记十三辙定名 → 找同韵字。
- **写稿改稿，检索同韵字表解疑**：判断平声字、仄声字、古入声字。

## 五、导学诗例

```
塞下曲
李白

五月天山雪，无花只有寒。
笛中闻折柳，春色未曾看。
晓战随金鼓，宵眠抱玉鞍。
愿将腰下剑，直为斩楼兰。
```

**成功底蕴揭示**：偶数句押韵（寒hán、看kān、鞍ān、兰lán），韵母都是ɑn，一韵到底，押平声韵。"看"在诗中读平声。
