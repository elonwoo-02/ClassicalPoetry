# 五绝格律

> 来源：杨祥雨《格律诗写作自学教程》第一编 第一章 第6讲
> 所属领域：格律基础

---

## 一、学习目标

掌握五言绝句的平仄格式和规则。

## 二、学习重点

1. 五绝的平仄相间、粘对规则。
2. 五绝四种平仄格式（由粘对规律推导）。

## 三、学习方法

用粘对规律，学格式推导。

## 四、核心要点

### 1. 平仄相间

- 平仄是诗句内部的声调关系，以两字为一节奏点，平仄交替，以求声调抑扬顿挫。
- 五绝的平仄，可以看成是在"平平—仄仄"或"仄仄—平平"的基础上再加上一个音节形成四种基本句式：
  1. 仄仄—平平—仄
  2. 平平—仄仄—平
  3. 平平—平—仄仄
  4. 仄仄—仄—平平

### 2. 粘对规则

- **对**：同一联内两句的平仄要相反（平对仄、仄对平）。
- **粘**：后联出句第二字的平仄要跟前联对句第二字一致（平粘平、仄粘仄）。
- "粘"的规则是很严格的，失对失粘是律诗的大忌。

### 3. 仄起与平起

- "仄起""平起"是指诗中第一句第二个字是仄声或平声。

### 4. 五绝四种格式

**格式一：第一句仄起不入韵（最基本格式）**
```
仄仄平平仄，平平仄仄平。
平平平仄仄，仄仄仄平平。
```

**格式二：第一句平起入韵**
```
平平仄仄平，仄仄仄平平。
仄仄平平仄，平平仄仄平。
```

**格式三：第一句平起不入韵**
```
平平平仄仄，仄仄仄平平。
仄仄平平仄，平平仄仄平。
```

**格式四：第一句仄起入韵**
```
仄仄仄平平，平平仄仄平。
平平平仄仄，仄仄仄平平。
```

## 五、导学诗例

```
宫词
张祜

故国三千里，深宫二十年。
一声何满子，双泪落君前。
```

**成功底蕴揭示**：这是第一种格式（仄起不入韵），五绝最基本格式。四句，每句五字，二四韵，平仄相间、粘对无误。

## 六、五绝平仄规则归结（四条）

1. 一联之中，平仄相对。
2. 两联之间，上联对句必须与下联出句平仄相粘。
3. 每句的平仄是相重的，又是相间的，构成近体诗长短升降的节奏；五言每句三个节奏。
4. 五言律绝，四句二韵或三韵，平仄定格凡四式。
