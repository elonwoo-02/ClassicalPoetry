# 七绝格律

> 来源：杨祥雨《格律诗写作自学教程》第一编 第一章 第7讲
> 所属领域：格律基础

---

## 一、学习目标

掌握七言绝句的平仄格律。

## 二、学习重点

1. 七绝是由五绝扩展而成（在五字句上加二字头，仄上加平、平上加仄）。
2. 七绝四种平仄格式。

## 三、学习方法

结合例诗，认真领会。

## 四、核心要点

### 1. 七绝的构成

将五言绝句扩展成七言绝句，办法是在五字句的上面加一个两字的头，仄上加平，平上加仄：

| 五言 | 七言 |
|------|------|
| 仄仄平平仄 | 平平仄仄平平仄 |
| 平平仄仄平 | 仄仄平平仄仄平 |
| 平平平仄仄 | 仄仄平平平仄仄 |
| 仄仄仄平平 | 平平仄仄仄平平 |

### 2. 七绝两种基本联

```
平平仄仄平平仄，仄仄平平仄仄平。
仄仄平平平仄仄，平平仄zz仄平平。
```

## 五、七绝四种格式

**格式一：第一句平起不入韵**
```
平平仄仄平平仄，仄仄平平仄仄平。
仄仄平平平仄仄，平平仄仄仄平平。
```

**格式二：第一句仄起入韵**
```
仄仄平平仄仄平，平平仄仄仄平平。
平平仄仄平平仄，仄仄平平仄仄平。
```

**格式三：第一句仄起不入韵**
```
仄仄平平平仄仄，平平仄zz仄平平。
平平仄仄平平仄，仄仄平平仄仄平。
```

**格式四：第一句平起入韵**
```
平平仄仄仄平平，仄仄平平仄仄平。
仄仄平平平仄仄，平平仄仄仄平平。
```

## 六、导学诗例

```
绝句
杜甫

两个黄鹂鸣翠柳，一行白鹭上青天。
窗含西岭千秋雪，门泊东吴万里船。
```

**成功底蕴揭示**：这是格式三（仄起不入韵）。平仄严格，粘对无误。七绝每句四个节奏，如"平平/仄仄/平平/仄"。

## 七、七绝平仄规则归结（四条）

1. 一联之中，平仄相对。
2. 两联之间，上联对句与下联出句平仄相粘。
3. 每句平仄相重相间，七言每句四个节奏。
4. 七言律绝，四句二韵或三韵，平仄定格凡四式。
