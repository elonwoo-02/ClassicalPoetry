# 六言绝句

> 来源：杨祥雨《格律诗写作自学教程》第一编 第一章 第10讲
> 所属领域：格律基础

---

## 一、学习目标

明白六言绝句也是近体诗之一，了解其格律。

## 二、学习重点

六言绝句的格律要求（平声韵、仄声韵格式）。

## 三、学习方法

自学，与五言、七言绝句对比同异。

## 四、核心要点

### 1. 基本定义

六言绝句，每句六个字。属近体诗范畴，有严格的格律要求。每句字数相等，平仄相对，一诗四句，偶数句入韵，一韵到底。

### 2. 三个基本句式

```
仄仄平平仄仄，平平仄仄平平。
平平平平仄仄，仄仄仄仄平平。
平平仄仄平仄，仄仄平平仄平。
```

### 3. 常见体——平声韵

**A. 仄起首句不押韵**：
```
仄仄平平仄仄，平平仄仄平平（韵）（对仗）。
平平仄仄平仄，仄仄平平仄平（韵）。
```

**B. 仄起首句押韵**：
```
仄仄平平仄平（韵），平平仄仄平平（韵）。
平平仄仄平仄，仄仄平平仄平（韵）。
```

**C. 平起首句不押韵**：
```
平平仄仄平仄，仄仄平平仄平（韵）（对仗）。
仄仄平平仄仄，平平仄仄平平（韵）。
```

**D. 平起首句押韵**：
```
平平仄仄平平（韵），仄仄平平仄平（韵）。
仄仄平平仄仄，平平仄仄平平（韵）。
```

### 4. 仄声韵

**A. 平起式**：
```
平平仄仄平仄（韵），仄仄平平仄仄（韵）。
仄仄平平仄平，平平仄仄平仄（韵）。
```

**B. 仄起式**：
```
仄仄平平仄仄（韵），平平仄仄平仄（韵）。
平平仄仄平平，仄仄平平仄仄（韵）。
```

### 5. 对仗特点

一联惯用对仗，可不对，有时两联全用对仗。

## 五、导学诗例

```
春景
李白

门对鹤溪流水，云连雁宕仙家。
谁解幽人幽意，惯看山鸟山花。

田园乐
王维

萋萋芳草春绿，落落长松夏寒。
牛羊自归村巷，童稚不识衣冠。
```
