# 生活醒悟点与第三思考层

> 来源：杨祥雨《格律诗写作自学教程》第二编 第五章 第20讲
> 所属领域：写作能力

---

## 一、学习目标

掏生活醒悟点，启动第三思考层。

## 二、学习重点

如何掏出生活醒悟点（独特感受、一得之见）。

## 三、学习方法

启动第三思考层。

## 四、核心要点

### 1. 生活的醒悟点

是指作者的独特感受，作者的一得之见。它是作者从工作、学习和生活中获取的真知灼见、哲理、新的创造物，是作者生命中一段刻骨铭心的历程的个性卓见，用属于自己的独特诉说方式传达。

### 2. 物我同思，思与境偕

**导学诗例**：王驾《雨晴》"雨前初见花间蕊，雨后全无叶底花。蛱蝶飞来过墙去，却疑春色在邻家。"——诗人巧妙使用拟人化，赋予蝴蝶人的情感，"却疑"是生活的醒悟点，又启动了第三思考层。"春天是美丽的，它永远留在人们的心底"——物我同思，思与境偕。

### 3. 用感觉物色鲜活感觉，目击道存

**导学诗例**：僧志南《绝句》"古木阴中系短篷，杖藜扶我过桥东。沾衣欲湿杏花雨，吹面不寒杨柳风。"——"沾衣欲湿杏花雨，吹面不寒杨柳风"是诗人写这首诗的生活醒悟点，"用感觉写感觉"启动了第三思考层。"吹面不寒杨柳风"是"目击道存"。

### 4. 在心灵震颤点上找源头活水

心灵震颤点即生活醒悟点。直觉获得审美表象 → 情感触动联想 → 联想唤起记忆表象 → 创造性想象重新分解组合 → 审美意象 → 主客交流与共鸣 = 心灵震颤点。

**导学诗例**：刘禹锡《石头城》"山围故国周遭在，潮打空城寂寞回。淮水东边旧时月，夜深还过女墙来。"——四个心灵震颤点：山、水、明月、城墙。"潮打空城""旧时月……还过女墙"寄寓对六朝兴亡和人事变迁的慨叹。
