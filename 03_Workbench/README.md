# 03_Workbench — 创作训练区

对应《格律诗写作自学教程》的学习过程，是实践与练习的场地。

---

## 目录结构

```
03_Workbench/
├── 名篇解析/         经典作品格律与章法解析
│   └── 杜甫-登高.md   范例文件
├── 格律训练/         格律格式辨识与标注
│   └── 01_五绝格律标注.md
├── 平仄练习/         平仄字判断与标注
│   └── 01_入声字辨识.md
├── 押韵练习/         押韵分析与十三辙使用
├── 对仗练习/         词性相对与对仗创作
│   └── 01_工对训练.md
├── 炼字练习/         炼动词、炼形容词等
├── 仿写训练/         以名篇为范本仿作
└── 创作实验/         自由创作实验
```

## 训练路径

按系统总览的建议顺序：
1. 先解析名篇，理解格律与章法。
2. 逐项专项训练（平仄 → 押韵 → 对仗 → 炼字）。
3. 仿写经典。
4. 自由创作实验。
5. 成熟作品移入 `04_Creations/`。
