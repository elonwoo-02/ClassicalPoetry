# 登高 · 名篇解析

> 作者：杜甫（唐代）
> 诗体：七律

---

## 原诗

```
登高
杜甫

风急天高猿啸哀，渚清沙白鸟飞回。
无边落木萧萧下，不尽长江滚滚来。
万里悲秋常作客，百年多病独登台。
艰难苦恨繁霜鬓，潦倒新停浊酒杯。
```

## 格律分析

- **平仄格式**：首句仄起入韵式。
- **押韵**：哀、回、来、台、杯——押平声灰韵。

## 对仗分析

- 颔联："无边落木萧萧下"对"不尽长江滚滚来"——"无边"对"不尽"（形容词）、"落木"对"长江"（名词）、"萧萧下"对"滚滚来"（拟声词+动词）。
- 颈联："万里悲秋常作客"对"百年多病独登台"——数量词"万里"对"百年"、动宾"悲秋"对"多病"、状中"常作客"对"独登台"。

## 章法结构

- **起**：首联写景，以急风、高天、猿啸、清渚、白沙、飞鸟六种意象绘制秋景图。
- **承**：颔联扩大境界——"无边落木""不尽长江"，空间上的无限延展。
- **转**：颈联转入人生——"万里悲秋常作客，百年多病独登台"，由景入情。
- **合**：尾联抒发身世之叹——"艰难苦恨繁霜鬓，潦倒新停浊酒杯"。

## 原书底蕴揭示

此诗被后人誉为"古今七言律第一"。
- 格律严谨：仄起入韵式，颔联颈联对仗工稳，粘对无误。
- 意境雄浑高远：风急天高、落木萧萧、长江滚滚——写尽秋之壮阔。
- 情感沉郁悲凉：万里悲秋、百年多病——八重悲意层层叠加（"万里"一悲、"悲秋"二悲、"常作客"三悲、"百年"四悲、"多病"五悲、"独登台"六悲、"艰难"七悲、"潦倒"八悲）。

## 可学习方法

- **格律层面**：仄起入韵式七律的典型代表，观察颔联颈联的对仗。
- **章法层面**：由景入情，从空间扩展到人生感慨的转折。
- **表达层面**：八重悲意的叠加渲染，"萧萧""滚滚"声音与画面并重。
- **创新层面**：以壮阔之景写深沉之悲，突破悲秋诗的格局。
